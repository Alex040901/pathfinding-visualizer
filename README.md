# Pathfinding Visualizer

A C++ project focused on implementing and understanding pathfinding algorithms. The project explores different search strategies for finding paths through a grid containing obstacles and weighted cells.

Currently, the algorithms are implemented as independent console applications. An interactive visualization using **SFML** is planned for a future development stage.

## Implemented Algorithms

| Algorithm | Description | Status |
|---|---|---|
| BFS (Breadth-First Search) | Explores the grid level by level to find the shortest path in an unweighted graph. | Completed |
| DFS (Depth-First Search) | Explores paths in depth before backtracking. | Completed |
| Dijkstra | Finds a minimum-cost path using weighted cells. | Completed |
| A* (A-Star) | Uses accumulated cost and a heuristic to guide the search toward the destination. | Completed |

## Features

- Grid-based pathfinding.
- Obstacle detection and avoidance.
- Orthogonal movement (up, down, left and right).
- Weighted cells for cost-based algorithms.
- Path reconstruction using parent coordinates.
- Comparison of accumulated path costs.

## Build and Run

This project uses CMake to configure and build its executables.

### Requirements

- C++ compiler compatible with the project.
- CMake.
- SFML 3.1.0 for the graphics test and future visualization.

### Build

Clone the repository:

```bash
git clone https://github.com/Alex040901/pathfinding-visualizer.git
cd pathfinding-visualizer
```

Configure the project:

```bash
cmake -S . -B out/build
```

Build an individual algorithm:

```bash
cmake --build out/build --target bfs
```

Replace `bfs` with `dfs`, `dijkstra` or `astar` to build another algorithm.

Run the executable generated by your build configuration.
